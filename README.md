### `README.md`

Eu desenho marcas e interfaces. Aos poucos, também transformo ideias em código aberto.

Meu trabalho vive no encontro entre direção visual, produto e engenharia — usando inteligência artificial como ferramenta de processo, não como atalho para o pensamento.

```txt
perfil/
├── design        identidades, interfaces e sistemas visuais
├── code          produtos, ferramentas e experimentos
├── ai            automação aplicada ao trabalho real
└── open-source   aprendendo em público, um commit por vez
```
